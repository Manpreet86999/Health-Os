# Health Os v0.1.0 - Windows runtime requirements
# This is a dependency manifest for users, not a Python installation list.
# Platform: Windows 10/11, x64 compatible.
# Node.js: official verified Node.js 24+ runtime included in runtime/node.exe.
# App: compiled web files included in dist/client; third-party browser modules
# are already bundled into the compiled JavaScript.
# Browser: Microsoft Edge, Google Chrome, or another supported modern browser.
# Main app: no separate npm, node_modules, Python, Java or build tools required.
# Internet: required for account sign-in, cloud sync and online services.
# Launch: double-click start.bat, or use the Health Os Start menu shortcut.
# Optional personal worker/research/voice tools are separate source features.
# Their Python requirements live in tooling/medical-research and scripts.
# Configure those tools separately; they are not required to start the web app.
